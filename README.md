Validador de CPF em Java

O programa:

- Pede para o usuário digitar um CPF
- Verifica se tem 11 números
- Confere se todos os caracteres são números
- Calcula os dígitos verificadores
- Informa se o CPF é válido ou inválido

- Exemplo
Digite o CPF (somente números):
12345678909
CPF válido!
Observações
Digite apenas números (sem ponto ou traço)
CPFs com todos os números iguais são inválidos

Objetivo:
Projeto feito para praticar Java e lógica de programação.
